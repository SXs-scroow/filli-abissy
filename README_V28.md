## Rodar

npm run dev

http://IP_DO_SEU_PC:5173

## Spotify
1. Crie um app em Spotify for Developers.
2. Cadastre exatamente a Redirect URI exibida na Câmara do Mestre.
3. Coloque o Client ID no painel ou em .env usando VITE_SPOTIFY_CLIENT_ID.
4. Clique em Entrar com Spotify. O login é OAuth automático do próprio Spotify.
5. Reprodução completa via Web Playback SDK exige Spotify Premium.

Não há Client Secret no projeto.
