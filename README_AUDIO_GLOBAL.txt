A PROFECIA — ÁUDIO GLOBAL (V40)

O sistema de música foi atualizado para funcionar sem Spotify para os Players.

COMO USAR
1. Entre como Mestre.
2. Abra Mestre > Música.
3. Escolha um arquivo de áudio (MP3 recomendado) ou informe uma URL direta.
4. Clique em "Enviar / salvar trilha global".
5. O arquivo é enviado para o bucket público do Supabase.
6. Todos os Players conectados recebem a mesma trilha, mesmo em outra internet.

CONTROLES
- Mestre: Play/Pause, Stop e Loop global.
- Todos: volume próprio.
- Minimizar: botão "−".
- Fechar: botão "×".
- Reabrir: botão flutuante com nota musical.
- Alguns navegadores exigem que o Player clique em "Ativar áudio da sessão" na primeira reprodução. Isso é uma proteção do navegador contra autoplay.

FORMATOS
MP3 é o formato recomendado.
Também são aceitos WAV, OGG/OGA, M4A, AAC, FLAC, OPUS e WEBM quando suportados pelo navegador do usuário.

LIMITE
O upload de música está limitado pelo site a 50 MB.

SUPABASE
Este projeto usa o mesmo bucket já criado:
a-profecia-assets

Não é necessário criar outro bucket se o SUPABASE_GLOBAL.sql da versão anterior já foi executado.
