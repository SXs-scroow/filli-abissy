V51 — BÔNUS EDITÁVEIS DAS PROFISSÕES SLASHER

- A aba Classes ganhou uma área exclusiva do Mestre para alterar os valores dos bônus das 7 profissões Slasher.
- Os valores são persistidos no estado global e sincronizados com os demais navegadores quando o Supabase global está ativo.
- Ao salvar, as fichas passam a usar imediatamente os novos valores no total efetivo de Atributos e Perícias.
- O bônus da profissão não consome os pontos de criação; ele é aplicado separadamente, como já acontecia com os bônus existentes.
- As classes da campanha principal permanecem com os bônus atuais.
- Compatibilidade retroativa: estados antigos recebem automaticamente os valores atuais das profissões.
- Nenhuma outra área foi alterada de propósito.
